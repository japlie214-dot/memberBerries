Hypotheses and checks:

1. Disable must not delete files. `disable` only writes `models/disabled` (`disabled_marker`); it does not touch variant directories. Confirmed by the test, which asserts `variant_dir(...).exists()` after disable.
2. `apply_default` honours the marker. It returns before setting any env var when `is_disabled(root)` (models.rs, `apply_default`, first condition). Explicit choices still win, as before. Confirmed.
3. Explicit settings unaffected. In diag.rs the disabled branch runs only when `port.is_none()`. An explicit `MEMB_GEMMA_MODEL_DIR` is handled earlier in `embedding_check` and returns before the disabled branch. An explicit port skips the disabled branch. Confirmed by reading the code order.
4. `ensure_embedding_model` (main.rs) returns early on `models::is_disabled(root)`. Confirmed.
5. Install clears the marker only on success (`let _ = remove_file` inside `Ok(n)`). Re-enable on a successful install is therefore correct. A failed install leaves the marker in place, which is the intended behaviour.
6. `enable` when already enabled returns 0 with "already enabled" (NotFound branch). Repeat `disable` overwrites the marker. Both are idempotent.
7. Arg parsing: an unknown argument after `disable` falls to `_ => return 2`. The bare `disable` command falls to the final `_ => 2` arm only for unknown commands. Confirmed.
8. `intra_threads()` accepts 1..=64, else defaults to 2. Zero, non-numeric and out-of-range values fall back to 2. The `with_intra_threads` call replaces the hard-coded 2 and nothing else changes.
9. Version bumps are consistent: Cargo.toml workspace, the four package manifests, CHANGELOG 0.11.0 entry, and wiki/Phase-Coverage.md. Install.md documents disable/enable and `MEMB_EMBED_THREADS`.
10. Minimality: the diff is limited to the marker, two arms, one status branch, one doctor branch and one env read. No validation or error handling was removed. Error paths for `disable`/`enable` print to stderr and return 1.

- The marker is `<root>/models/disabled`. It is the single source of truth, read by `apply_default`, `ensure_embedding_model`, `doctor` and `status`.

The hook figure (3.3 to 6.3 s with model, 0.4 s lexical) is not in the file, see Advisory C.

## Negative Discriminator Tests

Reasoned from `disable_stops_automatic_use_without_deleting_and_enable_restores_it`, which passed:

- While disabled, `apply_default` sets neither `MEMB_GEMMA_MODEL_DIR` nor `MEMB_EMBED_MRL_DIM`. The test asserts both are absent. A regression that ignored the marker would set them and fail.
- While disabled, `status` returns 1 ("installed but not in use"). Enabled, it returns 0. The test asserts both codes.
- While disabled, the files remain on disk. The test asserts `variant_dir(...).exists()`.
- Double `disable` returns 0; double `enable` returns 0 (the second hits the NotFound branch). Asserted.
- `disable --bogus` returns 2 (unknown argument arm). Asserted.
- After `enable`, `apply_default` sets `MEMB_GEMMA_MODEL_DIR` again. Asserted.
- An explicit `MEMB_GEMMA_MODEL_DIR` or `MEMB_EMBED_PORT` still wins when disabled: this is by code order (the early-return condition includes both, and diag checks the gemma env before the disabled branch). Not a separate test; noted as reasoned.
