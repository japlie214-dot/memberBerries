## Negative Discriminator Tests

Reasoned from the test assertions (these tests were run and pass; each negative case is asserted):

- Tampered content is never visible: `a_file_with_the_wrong_content_is_never_installed_and_a_damaged_file_is_replaced` (models.rs:405-409) asserts that install returns an error naming the file `onnx/model.bin` and "SHA-256", that the final file does not exist, and that the bad `.part` is removed. The rename happens only after hash match, so a wrong-content file cannot become visible.
- Damaged file of the right size is caught and replaced: same test, line 413-415. Size-only check reports `Present`; hashing reports `Corrupt`; a re-install then fetches it again and reports `Verified` (line 418-419).
- Missing file on the server fails the install with a resumable message (line 421-424).
- Resume uses HTTP Range: the loopback server records `range=Some(30000)` for the second half (line 387). A present file is not re-fetched: the second run's request log length is unchanged (lines 389-393).
- Explicit port or disable wins over the default directory: with a complete default directory, `MEMB_EMBED_PORT=1234` leaves `MEMB_GEMMA_MODEL_DIR` unset (line 451-453), and `MEMB_EMBED_DISABLE=1` also leaves it unset (line 455-457). Config-file port and gemma_model_dir reach `apply_default` as env values first (config.rs:330-342 before main.rs apply_default), so the same protection applies to config-file choices.
- One-byte size difference means incomplete: `set_len(size - 1)` makes `is_complete` false (line 462-463).
- Consent gating (not directly tested, reasoned from code): `install` without `--yes` on a non-terminal stdin takes the `confirm()` false branch and returns exit 1 before any network call (models.rs:188-197, 242-245). A test for this path is absent; recorded as an advisory gap, not a failure, because the consent branch is simple and visible.
